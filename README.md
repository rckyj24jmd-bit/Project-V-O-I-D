# PROJECT-VOID

Минималистичная 2D puzzle-platformer о времени, памяти и личности. Пять уровней, T-MODULE, детерминированные ловушки, терминальное вступление и финал.

## Запуск

Откройте `index.html` в современном браузере. Игра не требует установки, сборки, сети или внешних файлов. Первые 3,5 секунды экран намеренно чёрный; кнопки появляются примерно на седьмой секунде.

Для локального HTTP-сервера:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

## GitHub Pages

1. Загрузите `index.html`, `style.css`, `core.js`, `game.js` и `.nojekyll` в корень репозитория.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Откройте адрес, выданный GitHub Pages.

Относительные пути работают и в репозитории с собственным подкаталогом. Backend, аккаунты, cookies и постоянное хранилище отсутствуют. Archive и настройки существуют только до обновления страницы.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | A / D или стрелки |
| Прыжок | Space, W или ↑ |
| Подключить / отпустить T-MODULE | E |
| Изменить время при подключении | ← / → или ползунок |
| Двигаться при подключении | A / D |
| Пауза | Esc или MENU в углу |

На сенсорном устройстве доступны LEFT, RIGHT, JUMP, TIME. Время меняется ползунком; движение и прыжок продолжают работать одновременно. На мосту нужно поддерживать прошлое: на клавиатуре удерживать ← вместе с D, на телефоне возвращать ползунок влево при росте возраста конструкции. Для пропуска вступления удерживайте Space одну секунду или нажмите подпись пропуска.

Звук запускается после первого действия пользователя. SOUND, CRT EFFECT и SCREEN SHAKE переключаются в SETTINGS. Системное предпочтение уменьшенной анимации выключает CRT и встряску по умолчанию. При скрытии страницы звук приостанавливается. Потеря фокуса во время игры открывает паузу.

## Структура

- `index.html` — Canvas, меню, T-MODULE и сенсорные кнопки.
- `style.css` — моноширинный интерфейс, адаптивная раскладка и CRT.
- `core.js` — Player, Level, TimeSystem, данные пяти уровней. Фиксированный шаг 120 Hz; coyote time и jump buffer по 100 ms.
- `game.js` — Game, TModule, Dialogue, UI, AudioSystem, Particles, рисование и последовательности сцен.
- `tests/core.test.cjs` — физика и временные состояния.
- `tests/game.test.cjs` — полное прохождение на реальном игровом движке с заменой браузерной поверхности в Node, обработчики управления и переходы.
- `tests/browser.cjs` — дополнительный сценарий для Playwright и установленного Google Chrome; в текущей среде не выполнен из-за отсутствия разрешения на запуск браузера.

## Проверки

```sh
node --test tests/core.test.cjs tests/game.test.cjs
```

20 автоматических проверок проходят: физика, коллизии, обе механики прыжка, состояния объектов, пять уровней до финала, смерть и быстрый рестарт, распад моста без поддержания времени, пауза, потеря фокуса, управление после выбора ползунка и обработчики сенсорных кнопок.

Браузерная визуальная проверка, прослушивание звука и физический телефон остаются непроверенными: запуск тестового Chrome не был разрешён. Тесты в Node не заменяют эти проверки. Целевые 20–40 минут первого прохождения требуют человеческого плейтеста; искусственные задержки ради длительности не добавлены.
